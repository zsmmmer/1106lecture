# 塔蕴数智 · 讲座回放

数字与人文节气沙龙第 68 期，2026 年 11 月 6 日。主讲人张剑葳。

[打开讲座回放](https://zsmmmer.github.io/1106lecture/)

播放器以主录音为时间基准，默认使用经过降噪、语音均衡和响度整理的增强版。照片按原始拍摄时间排序并做透视裁切，换页点结合讲座内容估计。六段演示视频用同期声对齐，播放时由主录音发声。主持人在 1:02:51 开启现场交流。

同步讲稿是口语校订稿，整理了口头重复，听辨存疑处和整理说明用〔〕标出。下载面板提供增强录音、增强前的现场录音、TXT 讲稿、WebVTT 字幕、课件画面合集和六段演示视频。照片合集保留现场拍到的投影内容，部分原片存在遮挡或相机界面。

换页时上一张画面会保留到下一张就绪，演示结束后会保留末帧。画面下方的字幕可以开关。字幕由校订稿切分，部分短句的切换时间根据录音估计。手机上可在同步讲稿和画面索引之间切换，拖动时间轴时可预览画面。

## 本地预览

直接打开 `index.html`，或在站点根目录运行 `python3 -m http.server 8080` 后访问本地 8080 端口。网站的运行不依赖第三方脚本或后端服务。

## 内容和发布

- `lecture-data.js` 保存画面切换时间、讲稿区间和问答跳转点。时间以主录音开始后的秒数计。
- `assets/` 保存网页和下载使用的媒体文件。
- `main` 通过 GitHub Actions 运行浏览器验收，通过后发布到 GitHub Pages。
